Questions

Do I need CapCut on a computer?
For the full template, yes: it opens in CapCut for computer (the free download). Install it and open it once before you run the installer.
Can I use it on my phone?
Yes. Every template comes with a phone kit: the shot guide video, the shot list and the graphics as PNG images. In the CapCut phone app you add your clips and words, then place the graphics as overlays. The full animation is built for you in the computer version.
Is music included?
No sound files are included, so your Reel never gets muted for a song you don't have the rights to. Each template suggests a sound [SOUND PICKS]. Add it in Instagram after you upload: on a business account, Instagram only shows sounds cleared for business use.
Do I need to install any fonts?
No. The words you edit use Montserrat, which comes inside each template, and the big lettering is part of the artwork.
How do I change the words?
Double-click a text box in CapCut and type over the [brackets]. Keep it to a few words so people can read it in time.
My computer warns me about the installer. Is that normal?
Yes, Windows shows this for installers it hasn't seen before. Choose More info, then Run anyway.
What if I want a different clip in one shot?
Right-click the clip on CapCut's timeline, choose Replace, and pick another.
