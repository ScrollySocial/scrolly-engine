## C. Full Technical Findings

Checked directly against the live website on 2026-08-10, using publicly available tools only. No account access was used.

**Confirmed issues:**
- robots.txt file does not exist
- sitemap.xml, sitemap_index.xml, and a WordPress-standard sitemap path are all actively blocked by the server (returning a "Forbidden" response) rather than simply missing. This was confirmed by comparing against a genuinely nonexistent web address, which behaved differently
- Page title: "Landscaping and Garden Center." No business name, no location
- No meta description present
- Three top-level page headings exist where there should be one: "Landscaping and Garden Center," "About Mulberry Creek Garden Center," and "Contact Us"
- No structured business data (schema markup) found anywhere on the page
- The Facebook icon link points to "https://mulberrycreek/," a malformed, non-working address
- Several images carry placeholder-style labels ("Placeholder image for ABOUT," "Placeholder image for PRODUCT") or raw camera-roll/screenshot filenames as their descriptive text, and all images are hosted on a third-party website-builder's storage rather than the site's own. Consistent with template content that hasn't been fully replaced with real business photography and descriptions

**Minor items (low urgency):**
- A few contact-info links (address, email, phone number) have a smaller-than-ideal tap area on mobile screens
- One broken image reference exists, but only on the custom "page not found" error template. It does not appear on the live homepage
- A few product images are served at a notably larger file resolution than they're displayed at, which can add unnecessary load time

**Confirmed passing (checked, no issue found):**
- Secure connection (HTTPS) loads cleanly with no mixed-content warnings
- The site correctly redirects every common address variation (with/without "www," with/without "https") to one single, consistent address
- The page's canonical tag is set up correctly
- No "noindex" signal is blocking the page from search engines
- No layout-breaking issues at mobile screen widths
- Every resource on the live homepage (styles, scripts, images) loads successfully. No broken references on the page itself

**Lighthouse / Core Web Vitals results (homepage, the site's only page):**
- Performance 83/100, Accessibility 100/100, Best Practices 96/100, SEO 92/100
- Largest Contentful Paint: 3.4s · Cumulative Layout Shift: 0.001 · Total Blocking Time: 60ms
- Largest opportunity: unoptimized images (one image alone carries 1.7MB of avoidable weight; total page image weight exceeds 4MB), directly overlapping with the placeholder-image replacement already recommended in Part III
- Secondary opportunities: render-blocking resources (~1.4s potential savings), text compression (~191KB potential savings), HTTP/2 not in use

**Requires client access:**
- True Google indexing status, crawl history, manual actions/penalties, and search-performance data (clicks, impressions) all require direct access to the business's Google Search Console account.

## D. Content Opportunity Detail

We reviewed roughly 50 related search terms surfaced by a keyword-research tool to check whether an ongoing content/blog program would be justified. About one in five of those results turned out to be unrelated noise (driven by an unrelated popular online game that happens to share the word "garden") and were excluded. Of what remained relevant:

- Terms with real commercial search volume and manageable competition do exist around general landscaping topics (e.g., "landscaping services," "landscape design services," "landscape supply," "garden landscaping").
- The large majority of remaining relevant terms are generic, homeowner-facing "how to" and idea-list topics (front-yard ideas, garden soil, landscape edging) that are already thoroughly covered by large national publishers, not an open opportunity specific to a Wills Point-area business.
- Genuinely nursery/retail-specific topics were thin in this data. Only a handful of loosely related terms turned up, none closely matching Mulberry Creek's actual plant and tree inventory.
- One high-volume, low-competition term, "lawn care services," was deliberately excluded from consideration, since routine lawn/landscape maintenance falls outside the services Mulberry Creek offers.

This is the evidence behind the report's read that blog content isn't a first priority right now (not a finding that it would never be worthwhile).
