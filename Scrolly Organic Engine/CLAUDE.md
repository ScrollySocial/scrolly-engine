# Scrolly Organic Engine

A reusable, CMS-agnostic AI-assisted SEO operating system. This vault is its persistent memory.

## Structure
- `methodology/` — reusable Scrolly process docs, CMS/platform-agnostic. Load a file from here only when doing that phase of work.
- `clients/` — client-specific facts, research, and decisions (created per client as engagements start). Never mix client facts into `methodology/`.
- `current-state.md` — what's built, what phase we're in, what's next. Read this after this file to resume work.

## Working rules
- Never invent SEO metrics or business facts.
- Label all findings as one of: retrieved fact, client-provided fact, estimate, or AI inference.
- Don't duplicate information across files — link/reference instead.
- Load task-specific methodology files only when that task is active.

V0.1 — Discover. See `methodology/discover.md` when running a Discover engagement.
